## General
> This project was created by "Kenley & GarfieldTV" in 2024 and will hopefully be updated every few months.
> This project is the first ever self-made panel, which means bugs and errors are to be expected. However, they will be fixed in either major or minor updates, depending on the severity of the issue.
> This project will be developed with HTML, CSS, JS/NodeJS/TS, and some aspects will be handled with PHP.

### This panel will have the following functions:
- Container/(also known as eggs) creator.
- Theme creator.
- Language translation support.
- Settings editor in the Admin Panel.
- No need for Nginx, Apache, or any third-party web service (aside from PHP).
- Panel synchronization.
- License system.
- Marketplace for plugins and themes.
- And plenty more...
